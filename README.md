本项目基于开源项目 [sganggs] 提供的框架，实现了一个全新角色的完整实装。在此过程中，我利用大语言模型（DSH/GPT）完成了底层文件冲突排查、资源映射重构与引擎适配。

🛠️ 核心技术点与难点攻克
逆向资源工程：通过 F12 抓包与资产分析，精准定位并提取了 Spine 骨架模型（.atlas / .json），解决了传统 AI 无法处理二进制资源包的痛点。

冲突排查与AI协同：在注入新角色 ID 时遭遇游戏引擎死锁崩溃，通过向本地 Agent (DSH) 提供核心报错日志与最小复现代码，借助 AI 快速定位并解决多角色配置冲突。

贴图与坐标系重构：针对引擎的 UV 坐标错位问题，利用多模态视觉模型辅助计算，修正了图集（Atlas）的 XYZ 轴映射参数，实现完美渲染。
